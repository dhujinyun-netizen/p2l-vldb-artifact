01 / Hierarchical execution

Hierarchical keys deserve
hierarchical execution.

A semantic ID is not a flat sentence. Its early codes route a query into a region; its later codes refine candidates inside that region.

Sequential decoding applies the same expensive operator at every level. P2L changes the operator when the index has already done the localization work.

Sequential

Commit, score, prune.
Repeat.

Every unresolved position becomes another dependent decision.

or
Prefix-to-Leaf

Localize, expose,
rank together.

Delay the next pruning decision until suffix evidence arrives.

05 / The method

Three moves. One shared predictor.

01

Localize

Traverse the Candidate Trie only long enough to find a useful prefix region.

02

Expose

Enumerate the complete descendants that actually exist beneath retained prefixes.

03

Rank

Aggregate unresolved-position evidence, then optionally refine paths with PCAA.

OPTIONAL REFINEMENT

PCAA follows the residual direction.

After a prefix is reconstructed, each candidate codeword is compared with the remaining query direction and standardized within its codebook.

query−prefix reconstruction=residual direction→codeword affinity
