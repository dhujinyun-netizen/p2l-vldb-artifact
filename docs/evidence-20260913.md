# P2L project-page evidence — 13 September 2026

This page reports the current research manuscript, **Prefix-to-Leaf: Deferred
Selection and Shared Suffix Scoring for Semantic-ID Retrieval**. These are
existing measurements, not new experiments run for the website redesign.

## Current configuration

Independent-Suffix P2L; prefix depth s=3 (including the modality code), B=K=50,
lambda=0. The checkpoint, realized semantic-ID index, and reranker are fixed
in the matched comparisons. Suffix positions condition on the query and
retained prefix without cross-position suffix attention. This differs from
the older Interacting-Suffix configuration as well as PCAA configurations.

## Result provenance

Values are transcribed from the authors' current manuscript tables and
supplementary table `matched_all16_local_lambda0.tex`, dated 12 September
2026. The website's complete 16-task table preserves their reported precision.
The manuscript and underlying large experimental assets are not redistributed
by this website update.

| Comparison | Scope | Reported result |
|---|---|---|
| Matched Sequential vs Independent-Suffix P2L | 16 LOCAL tasks | Macro R@10 39.36% to 43.64%; +4.28 points; paired-query 95% CI [4.03, 4.53] |
| Frozen level-wise vs frozen P2L selection | 4 tasks, fixed Independent-Suffix scorer | Macro R@10 40.09% to 48.24%; +8.15 points |
| Repeated latency comparison | 4 tasks, RTX 3090, batch 1, 5 repeats | Generation lower by 41.6–42.3%; decode-to-rerank lower by 39.4–40.0% |
| UNION comparison | 5,609,079 items, CIRR-7 and EDIS-2, batch 8 | R@10 +3.19/+9.69 points; generation latency lower by 48.7%/46.1% |

All 16 matched point estimates improve; 14 paired-query intervals exclude
zero. Confidence intervals condition on the selected implementation and do
not account for implementation selection informed in part by test results.
The frozen-scoring +8.15-point result is a separate counterfactual comparison,
not an additive explanation of the +4.28-point matched gain. Generation starts
from cached query embeddings; neither timing boundary is raw-query service
latency. Top-K is exact within the enumerated retained frontier, not globally.

## Release boundary

The immutable **v1.0.0** release predates this manuscript revision. Its bundled
16-task table reports the older 42.83% P2L macro, and its historical final
configuration uses PCAA with lambda=20. Neither should be relabeled as the
current 43.64% Independent-Suffix result. Existing files under `docs/results/`
and the release audit remain historical evidence; this documentation update
does not replace those results or claim that the archive reproduces the new
configuration. A separately validated code/evidence release is needed to
close that version gap.

The framework graphic is rendered from the authors' revised hierarchy-fixed
PPT (13 September 2026); its example thumbnails are schematic rather than
measured retrieval rankings. No manuscript PDF, supplementary PDF, checkpoint,
or dataset is added by this update.
