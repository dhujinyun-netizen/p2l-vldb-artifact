# P2L project-page evidence — 13 September 2026

This page reports the current research manuscript, **Prefix-to-Leaf: Deferred
Selection and Shared Suffix Scoring for Semantic-ID Retrieval**. These are
existing measurements, not new experiments run for the website redesign.

## Current configuration

Independent-Suffix P2L; prefix depth s=3 (including the modality code), B=K=50,
lambda=0. The checkpoint, realized semantic-ID index, and reranker are fixed
in the matched comparisons. Suffix positions condition on the query and
retained prefix without cross-position suffix attention. This differs from
the older Interacting-Suffix configuration as well as PCAA configurations.

## Result provenance

Values are included as lightweight CSV evidence in this branch. The no-data
audit recomputes the three 16-task policy macros, validates the four-task
depth grid, and checks the 16 matched task-width points used by manuscript
Figure 4. The manuscript and underlying large experimental assets are not
redistributed.

| Comparison | Scope | Reported result |
|---|---|---|
| Matched Sequential vs Independent-Suffix P2L | 16 LOCAL tasks | Macro R@10 39.36% to 43.64%; +4.28 points; paired-query 95% CI [4.03, 4.53] |
| Frozen level-wise vs frozen P2L selection | 4 tasks, fixed Independent-Suffix scorer | Macro R@10 40.09% to 48.24%; +8.15 points |
| Candidate-width sweep | 4 tasks; B=K in {10,20,50,100}; batch 8 | P2L has higher R@10 and lower identifier-generation latency in all 16 matched task-width pairs; gain 0.71–14.34 points; speedup 1.51–2.44x |
| Repeated latency comparison | 4 tasks, RTX 3090, batch 1, 5 repeats | Generation lower by 41.6–42.3%; decode-to-rerank lower by 39.4–40.0% |
| UNION comparison | 5,609,079 items, CIRR-7 and EDIS-2, batch 8 | R@10 +3.19/+9.69 points; generation latency lower by 48.7%/46.1% |

The Figure 4 point values are stored in
`docs/results/candidate_width_sweep.csv`; the corresponding plotting entry
point is `scripts/structnar/plot_candidate_width_sweep.py`. The width sweep
varies K together with B and excludes downstream reranking latency, so it is a
generation-side operating-point study rather than an end-to-end Pareto claim.

All 16 matched default-policy point estimates improve; 14 paired-query
intervals exclude zero. Confidence intervals condition on the selected
implementation and do not account for implementation selection informed in
part by test results. The frozen-scoring +8.15-point result is a separate
counterfactual comparison, not an additive explanation of the +4.28-point
matched gain. Generation starts from cached query embeddings; neither timing
boundary is raw-query service latency. Top-K is exact within the enumerated
retained frontier, not globally.

## Artifact snapshot boundary

The historical **v1.0.0** release contains an older PCAA configuration with
lambda=20 and must not be presented as reproducing the current manuscript.
The later **v2.0.0** release matches the Independent-Suffix lambda=0 default
but predates the manuscript's candidate-width Figure 4 evidence. The current
submission-facing artifact therefore uses the immutable repository commit
permalink cited in the paper rather than relabeling an older release tag.
That snapshot includes the Figure 4 CSV, plotting entry point, and updated
no-data audit together with the existing 16-task and validation-depth evidence.

Full reproduction still requires the separately distributed assets listed in
the README: the official M-BEIR release, frozen CLIP/RQ50 assets, the P2L
checkpoint, and candidate semantic-ID/Trie artifacts. No manuscript PDF,
supplementary PDF, dataset, or model checkpoint is added by this evidence
update.
